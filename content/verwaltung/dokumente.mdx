# Dokumente

## Uploads prüfen

Unter **Dokumente** → **Uploads** sehen Sie alle von Eltern hochgeladenen Dateien. Ein Badge zeigt die Anzahl ausstehender Prüfungen an.

Für jedes Dokument können Sie:

- **Annehmen** — Das Dokument wird in den Bereich Finanzen oder Verwaltung verschoben
- **Ablehnen** — Das Dokument wird abgelehnt, optional mit Begründung

## Upload-Anfragen

Sie können Eltern gezielt auffordern, bestimmte Dokumente hochzuladen:

1. Erstellen Sie eine Upload-Anfrage unter **Uploads**.
2. Die Anfrage erscheint im Elternportal unter **Meine Uploads**.
3. Nach dem Upload prüfen Sie das Dokument und akzeptieren oder lehnen es ab.

## Synchronisierungsverlauf

Unter **Sync-Verlauf** sehen Sie die Historie der Dokumentensynchronisierung mit externen Systemen. Bei Bedarf können Sie eine manuelle Synchronisierung auslösen.
