# Änderungsanträge

Eltern können über das Portal Änderungen an ihren Stammdaten oder ihrer Adresse beantragen. Diese Anträge werden Ihnen zur Prüfung vorgelegt.

## Übersicht

Unter **Änderungsanträge** sehen Sie alle eingegangenen Anträge. Ein Badge zeigt die Anzahl offener Anträge an.

## Antrag bearbeiten

Für jeden Antrag können Sie:

- **Details einsehen** — Sehen Sie die beantragten Änderungen im Vergleich zu den aktuellen Daten
- **Anhänge prüfen** — Eltern können Nachweisdokumente an ihre Anträge anhängen
- **Aktivitätsverlauf** — Sehen Sie alle bisherigen Aktionen mit Zeitstempel und Bearbeiter

## Aktionen

- **Annehmen** — Die Änderungen werden in die Datenbank übernommen
- **Ablehnen** — Der Antrag wird abgelehnt. Sie können optional einen Ablehnungsgrund angeben
- **Schließen** — Der Antrag wird ohne Übernahme geschlossen
- **Wiedereröffnen** — Ein geschlossener Antrag kann erneut geöffnet werden

## Archiv

Bearbeitete Anträge werden archiviert und können über den Filter eingesehen werden.
