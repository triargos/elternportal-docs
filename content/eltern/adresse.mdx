# Meine Adresse

Unter **Meine Adresse** sehen Sie die aktuell bei der Schule hinterlegte Adresse Ihrer Familie.

## Adressdaten

Folgende Informationen werden angezeigt:

- Straße und Hausnummer
- Postleitzahl und Ort
- Ortsteil
- Landkreis
- Land
- Postfach (falls vorhanden)

## Umzug melden

Bei einem Umzug können Sie Ihre neue Adresse direkt über das Portal melden:

1. Navigieren Sie zu **Meine Adresse**.
2. Klicken Sie auf **Adresse ändern**.
3. Wählen Sie aus, welche Familienmitglieder an die neue Adresse umziehen.
4. Geben Sie die neue Adresse ein.
5. Senden Sie den Änderungsantrag ab.

Wenn alle Familienmitglieder umziehen, wird die bestehende Adresse aktualisiert. Bei einem Teilumzug wird eine neue Adresse für die ausgewählten Mitglieder angelegt.

Die Adressänderung muss von der Schulverwaltung bestätigt werden.
