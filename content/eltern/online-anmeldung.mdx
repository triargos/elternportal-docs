# Online-Anmeldung

Über die **Online-Anmeldung** können Sie Ihr Kind für Schulangebote, Veranstaltungen oder direkt an der Schule anmelden.

## Verfügbare Anmeldungen

Auf der Übersichtsseite sehen Sie alle aktuell verfügbaren Anmeldeformulare. Jede Anmeldung zeigt:

- Name und Beschreibung
- Verfügbarkeitszeitraum
- Status (offen / geschlossen)

## Anmeldung ausfüllen

Der Anmeldeprozess besteht aus mehreren Schritten:

### 1. Sorgeberechtigte angeben

Geben Sie die Daten der Sorgeberechtigten (Eltern/Erziehungsberechtigte) an. Bei einer externen Anmeldung müssen Sie diese neu erfassen, bei einer internen Anmeldung werden vorhandene Daten übernommen.

### 2. Kinder hinzufügen

Fügen Sie die Kinder hinzu, die Sie anmelden möchten, und füllen Sie deren Daten aus.

### 3. Formulardaten ausfüllen

Je nach Anmeldung werden zusätzliche Informationen abgefragt — z.B. Kurswahl, besondere Bedürfnisse oder weitere Angaben.

### 4. Zusammenfassung prüfen

Vor dem Absenden sehen Sie eine Zusammenfassung aller eingegebenen Daten. Prüfen Sie diese sorgfältig.

### 5. Absenden

Nach dem Absenden erhalten Sie eine Bestätigung. Die Schule wird Ihre Anmeldung bearbeiten und sich bei Rückfragen bei Ihnen melden.
