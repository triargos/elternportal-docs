# Willkommen im Elternportal

Hier finden Sie Anleitungen und häufig gestellte Fragen zur Nutzung des Elternportals.

## Erste Schritte

- **Anmelden**: Nutzen Sie die Zugangsdaten, die Sie von der Schule erhalten haben.
- **Profil bearbeiten**: Aktualisieren Sie Ihre Kontaktdaten unter "Mein Profil".
- **Nachrichten**: Kommunizieren Sie direkt mit der Schule über das Nachrichtensystem.
