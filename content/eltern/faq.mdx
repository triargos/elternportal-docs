# Häufige Fragen

## Wie ändere ich mein Passwort?

Navigieren Sie zu **Einstellungen** → **Sicherheit**. Dort können Sie ein neues Passwort vergeben.

## Wie bearbeite ich meine Stammdaten?

Unter **Meine Familie** können Sie die Daten Ihrer Familienmitglieder einsehen und Änderungsanträge stellen. Änderungen müssen von der Verwaltung bestätigt werden.

## Wie lade ich Dokumente hoch?

Unter **Meine Dokumente** → **Meine Uploads** können Sie Dateien hochladen, sofern eine Upload-Anfrage der Schule vorliegt.

## Wie melde ich einen Umzug?

Unter **Meine Adresse** können Sie eine Adressänderung beantragen. Wählen Sie die betroffenen Familienmitglieder aus und geben Sie die neue Adresse ein.

## Mein Änderungsantrag wurde abgelehnt — was tun?

Prüfen Sie den Ablehnungsgrund unter **Änderungsanträge**. Sie können einen neuen Antrag mit korrigierten Daten oder zusätzlichen Nachweisen stellen.

## Wie aktiviere ich die Zwei-Faktor-Authentifizierung?

Unter **Einstellungen** → **Sicherheit** können Sie 2FA mit einer Authenticator-App (z.B. Google Authenticator) einrichten.

## An wen wende ich mich bei Problemen?

Bei technischen Problemen oder Fragen zur Anmeldung wenden Sie sich bitte an das Sekretariat Ihrer Schule.
