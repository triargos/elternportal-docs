# Dokumente & Uploads

## Meine Dokumente

Unter **Meine Dokumente** finden Sie alle Dokumente, die Ihnen von der Schule bereitgestellt wurden. Sie können die Dokumente nach Familienmitglied filtern und herunterladen.

## Meine Uploads

Unter **Meine Uploads** können Sie Dokumente an die Schule übermitteln. Die Schule kann Upload-Anfragen erstellen, wenn bestimmte Unterlagen von Ihnen benötigt werden.

### Dokument hochladen

1. Navigieren Sie zu **Meine Uploads**.
2. Wählen Sie die offene Upload-Anfrage aus.
3. Laden Sie die gewünschte Datei hoch.
4. Senden Sie den Upload ab.

### Upload-Status

Ihre hochgeladenen Dokumente haben einen der folgenden Status:

- **Ausstehend** — Das Dokument wird noch geprüft
- **Genehmigt** — Das Dokument wurde akzeptiert
- **Abgelehnt** — Das Dokument wurde abgelehnt (laden Sie ggf. eine korrigierte Version hoch)
- **Storniert** — Der Upload wurde storniert

Unter **Archiv** können Sie bereits bearbeitete Uploads einsehen.
